# Safe Harbour v1 · proposed prospective challenge

Prepared 8 October 2026. **Design brief only; not enabled, locked or retrospectively scored.** Test the appeal with the holder pilot before implementing. Daily Tide v1, Tidal Trio v1, paper v1, historical scores and DNA remain frozen.

A holder chooses one familiar preset and an owned whale as its badge before a shared UTC start. The question is: can this preset finish a three-day watch above its starting balance while keeping drawdown within a disclosed budget? The daily recap supplies the story between start and finish; participants never write a strategy.

Proposed objective: a common 72-hour forward window, $1,000 simulated starting capital, neutral DNA and the existing trend/breakout/mean-reversion presets. Qualifying outcomes finish with positive net return and worst drawdown at or below 1%. Rank qualifying presets by net return after modeled costs, with equal results tied; if none qualify, say so. The 1% budget is a proposed game constraint, not tuned on old results or an established risk target. Ask testers whether it makes the choice enjoyable before locking it.

Use the existing UBTC/USDC venue, causal next timely close and disclosed 0.08% fee/0.05% slippage per side. Each preset has one shared executor; holder picks do not create independent strategy trials. An owned badge personalises the pick but changes no preset statistics. No deposits, real orders, prizes, WWAX or profitability claims.

Before enabling, publish a separate immutable rules document/hash with exact start/end/deadline, reference allocation, capacity, costs, tie precision and qualifying rules. Join requires explicit public consent and server-side same-block ownership. Picks lock before the common start. Do not attach a new objective to an existing Tide round or rewrite partial history.

Only all 864 timely, gap-free five-minute closes qualify for final rankings. An interrupted window retains dated partial results without final ranks or invented catch-up fills. Decide whether restarting under a new prospective ID is worthwhile; never reset the interrupted record. With Free hosting, labelled interruption is preferable to disguising an incomplete contest.

Implementation gate: reliable multi-day Free-plan evidence and real desktop/mobile holder acceptance, followed by pilot feedback. Prototype two plain-language invitations locally for interviews: “Pick the highest return over one day” (existing Daily Tide) and “Finish green while protecting the budget over three days” (proposed Safe Harbour). Ask which they would return to and why. Preference is not proof of retention.

Acceptance for a later implementation: different rules hash/record namespace; future-only joins; immutable consent/badge/pick; no company-draft mutation; accelerated complete/partial/no-qualifier/tie fixtures; real UTC window; mobile deadline clarity; measured returns distinguished from shares and picks.
